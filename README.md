Jensen Huang as CEO and shares soar 31%, a suspected North Korean jet breaches

hundreds of schools in Germany and Denmark, a candy factory fire in Indonesia
kills 24, a report finds 99% of Gaza shows toxic contamination, O'Hare grounds
flights in the Thanksgiving rush, and Denmark's top court upholds the
"ghetto law" evictions.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) copies `entry.png` to
`$MAKEFUN_OUTPUT_DIR/entry.png`.
